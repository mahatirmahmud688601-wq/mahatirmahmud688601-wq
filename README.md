## About

I enjoy turning ideas into practical products—from the first interface sketch to a working application. My work combines **Android development, modern web technologies, thoughtful UX, automation, and artificial intelligence**.

- Building Android apps with **Kotlin and Jetpack Compose**
- Creating modern web experiences with **React, TypeScript, JavaScript, and Node.js**
- Exploring AI assistants, intelligent workflows, and productivity tools
- Focused on simple interfaces, maintainable code, and meaningful user experiences
